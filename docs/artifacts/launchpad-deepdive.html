01

The substrate — how STAS behaves

Everything the launchpad does is spending and re-creating UTXOs under the STAS colored-coin rules. Four behaviours define what's possible.

↳

Supply is minted once. Issuance creates the full token supply inside UTXOs. "Total vs public" is just how you slice those UTXOs — public allocation to the sale pool, the rest to treasury/team/rewards addresses.

↳

Transfer = spend + recreate. Sending tokens spends STAS UTXOs and creates new ones for the recipient, following the protocol script. There are no balances — only coins.

↳

Split & merge. One STAS UTXO of 1,000 tokens splits into 300 + 700; small ones merge back. This is how a buyer gets an exact amount and how the pool makes change.

↳

Vesting = timelocks. Team/treasury tranches are STAS UTXOs locked with nLockTime / CLTV — unspendable until a block height/time. Native, no contract needed.

The one constraint to design around

Any "shared pool everyone hits at once" (AMM, bonding curve, staking vault) is a single-UTXO-contention problem — one spender per step. The hybrid model sidesteps it: the operator sequences purchases and settles them on mainnet, so users never race for the same UTXO.

02

Pricing — fixed now, curves as the study track

MVP ships a fixed price (X sats / token). The next question is dynamic pricing: a bonding curve makes price a deterministic function of supply sold, so the curve itself is the market maker. Three shapes, same axes — pick the aggression.

Price ↑  vs  supply sold →
Linear Exponential Constant-product

Linear

price = m · sold + b

Steady, legible climb. Easiest to explain to buyers; mild early-buyer advantage.

Exponential

price = b · e^(k · sold)

Cheap early, expensive late. Strong early-buyer reward — can read as predatory; use with care.

Constant-product · x·y=k

price = reserve_sats / reserve_tokens

The Uniswap model. Best-understood two-sided market; supports sell-back. Steepens sharply as the pool drains.

On UTXO: a single stateful "curve UTXO" carrying k and reserves, spent-and-recreated per trade.

Path to it

A curve is a stateful contract (must remember sold). Sequence: fixed-price → operator-enforced curve with published state → sCrypt covenant enforcing the math on-chain. Curves invite front-running / MEV — model those failure modes before real value flows.

Tokenomics — the distribution is the design

STAS handles supply and transfer; the value question is how you split and release it. A worked example of a 100M-token project — the numbers are a starting template, not a prescription.

Vesting

Team & treasury don't unlock at once. Slice each into tranches as separate timelocked STAS UTXOs (e.g. quarterly cliffs) — the schedule is enforced by CLTV, visible on-chain.

Emissions

Staking rewards flow over time from the rewards pool. The emission curve (flat, decaying, halving) is its own tokenomic lever — front-loaded emissions bootstrap; decaying emissions protect late holders.

Sinks & burns

Optional demand levers: burn a slice on certain actions, or route value to treasury. On UTXO a "burn" is a provably-unspendable output. Keep out of MVP; note as a lever.
